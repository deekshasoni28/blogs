# Data Types in Python 🧩

Data types define the type of value a variable can store.

## 🔹 Common Data Types in Python
- int → Integer numbers (e.g., 10, 25)  
- float → Decimal numbers (e.g., 10.5, 3.14)  
- str → Text or string (e.g., "Hello")  
- list → Collection of items (e.g., [1, 2, 3])  

## 🔹 Example
```python
x = 10        # int
y = 3.14      # float
name = "Deeksha"  # string
numbers = [1, 2, 3]  # list
